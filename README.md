# 📊 Excel Analytics Lab

### 🛒 Retail Data Analysis | 9 Hands-On Excel Workbooks

## 📌 Project Overview

This repository contains **9 Excel workbooks** covering spreadsheet fundamentals, formulas, data cleaning, lookup functions, and retail data analysis using DMart practice datasets.

The project focuses on organizing data, applying Excel functions, analyzing sales and inventory, and exploring meaningful patterns in retail datasets.

## 📂 Project Workbooks

| # | Workbook | Key Focus |
| 📗 01 | **Excel Fundamentals** | Spreadsheet basics and data organization |
| 🧮 02 | **Excel Formulas & Functions** | Calculations and logical functions |
| 🧹 03 | **Data Cleaning & Preprocessing** | Data consistency and preparation |
| 🛒 04 | **DMart Retail Data Analysis** | Retail dataset exploration |
| 📈 05 | **DMart Sales Analysis** | Sales data analysis |
| 📦 06 | **DMart Inventory Analysis** | Inventory data exploration |
| 🔍 07 | **Advanced DMart Data Analysis** | Advanced analytical exercises |
| 🔗 08 | **Lookup Functions** | Data matching and retrieval |
| 📊 09 | **DMart Retail Analytics Practice** | Applied retail analysis |
